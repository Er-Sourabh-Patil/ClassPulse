Bulk-create student records and login accounts from a spreadsheet.

Upload CSV file

Required columns: PRN and Student Name. Optional column: Batch.

Maximum 2 MB and 1,000 rows per import. UTF-8 CSV is recommended.
Used only when the CSV has no Batch column or a row's batch is blank.

CSV format example

PRN,Student Name
260840325001,Aayush Chaudhary
260840325002,Abhay Pandurang Lahane

Existing PRNs and duplicate PRNs within the file are skipped. Passwords are generated and stored as secure hashes.

Before you import

  • Each imported student receives a unique login ID.
  • A random temporary password is generated for each account.
  • Existing PRNs are not overwritten.
  • All new accounts are created in one database transaction.
  • Save the generated credentials securely and share them privately with students.
